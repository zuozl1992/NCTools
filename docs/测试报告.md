最终构建：`cmake --build /private/tmp/nctools-tcpserver-build -j 4` 成功，包含应用和全部测试目标。

最终全量测试：从构建根目录运行 `ctest --output-on-failure`，5/5 套件通过、0 失败。覆盖数据处理、设置、传输、控制器和 QML 交互。

边界：TCP/串口的待写队列清空只能确认本机已交给底层传输，不能证明远端应用已处理；若需端到端确认，通信协议必须有对端确认消息。

QML 测试从源码路径直接加载 `Main.qml`，因此图标的 `qrc:` 路径在该测试中不可用；加载时还出现 Qt Basic Dialog 的 `implicitWidth` 绑定循环警告。两者不影响本次 15 项测试判定，仍建议单独检查弹窗布局。
